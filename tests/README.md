# 匿名流水与业务用例

`factory.security_identity(index)` 将 `0..99` 映射为六位编号 `0000xx` 和四字名称，例如 `000012` 对应 `证券一二`。
`factory.write_statement(path, columns, rows)` 根据指定列顺序写出固定宽度流水，默认使用 UTF-8；显式编码参数用于覆盖旧平台导出编码。

`fixtures/` 仅保留 21 条自包含的核心流程流水：招商证券 13 条、东方财富证券 8 条。两平台共用匿名证券编号，覆盖独立成本核算后的合并；表头和逆回购数量单位体现平台差异，未披露的费用列使用缺省值。

运行 `python -m tests.generate_fixtures` 可重新生成确定性的 UTF-8 样本。生成器不读取或修改 `data/`、`out/`，也不调用被测解析或核算代码计算预期。

`expected.json` 的金额按以下流程手工推导：

- 招商证券：证券零零两次买入成本 `1005 + 2005 = 3010`，卖出四分之一，移除成本 `752.50`，卖出收益 `994 - 752.50 = 241.50`，剩余成本 `2257.50`；股息扣税后收益 `100 - 20 = 80`。
- 招商证券：证券零一托管转入估值 `1000`，转出四成移除成本 `400`、估值 `600`，收益 `200`，剩余成本 `600`，托管净转入 `400`。
- 招商证券：证券零二逆回购本金 `1000`、佣金 `1`，购回 `1003`，净收益 `2`；交收修正另记 `1003`。加上现金利息 `1.25`，总收益 `524.75`，剩余成本 `2857.50`，手续费 `17`（含印花税 `1`）。银行净投入 `10000 - 2000 = 8000`，账户净投入 `8400`。
- 东方财富证券：证券零零买入 `2005` 后全部卖出 `2193`，收益 `188`；证券零二逆回购 `1001` 拆出、`1004` 购回，收益 `3`，再次拆出扣费 `1` 后留存本金 `1000`。加上现金利息 `2`，总收益 `192`，手续费 `14`（含印花税 `2`），银行及账户净投入 `5000 - 500 = 4500`。
- 合并：收益 `716.75`，剩余成本 `3857.50`，手续费 `31`，印花税 `3`，银行净投入 `12500`，账户净投入 `12900`。

独立业务用例继续覆盖移动加权成本、分红税、托管转移、逆回购、现金配对、平台独立核算、未知业务保留、跨文件重复次数、字段别名和缺省值、一次表头绑定及编码。
