# 核算与策略口径

- 现金净投入 = 银行转存 − 银行转取；证券转托不按现金计入。
- 账户净投入 = 现金净投入 + 托管净转入。托管净转入按成交金额计算，转入为正、转出为负；同一证券多笔转移累加为净额。保留这一口径是为了让只有托管转入、没有银行入金的账户也具有投入基数。跨账户合并时，如果转出和转入采用的估值不同，期间价格变化会使托管净转入不能完全抵消，并随之影响账户净投入及收益率；因此账户净投入表示按各账户流水估值后的核算投入，不等同于实际投入的现金，后者应查看现金净投入。
- 概览中的收益率 = 已实现净收益 ÷ 账户净投入，仅在账户净投入为正时计算。净投入为零或负数时显示“—”；累计取出超过投入不代表亏损，也不能以负投入计算投资回报率。存在未识别业务或缺失托管金额时，收益率基于已知金额并同时标注收益不完整。
- 交易总额 = 证券交易总额 + 逆回购交易总额。证券交易总额为证券买入和证券卖出的发生金额绝对值之和；逆回购交易总额为拆出发生金额绝对值之和，购回作为到期交收不计入交易总额。两项均包含手续费，不包含其他资金流水。交易手续费合计显示其占交易总额的千分比，费用分项分别显示其占交易总额的千分比及占手续费的百分比。
- 股票已实现收益使用移动加权成本：买入净支出进入持仓成本，卖出净收款
  减去相应数量的持仓成本。尚未卖出部分只显示历史成本，不计算浮动收益。
  盘后定价买、盘后买按证券买入核算，盘后定价卖、盘后卖按证券卖出核算。
- 分红及补缴红利税按发生金额计入证券收益；资金利息单列并计入总收益，其备注收益率 = 资金利息 ÷ 账户净投入，账户净投入非正时显示不可计算。
- 托管转入使用成交金额作为本账户的新增持仓成本，单位成本为成交金额除以数量，不追溯其他账户的原始买入成本。
  托管转移以流水披露的成交金额或数量与单价估值，不推断价格来自开盘还是收盘；两端估值的差额体现在各账户收益中。托管金额不作为银行转账处理。
  成交金额、数量、单价优先保留原始字段，缺少其中一项时根据另外两项推算（除数不能为零）。招商托管记录使用成交价格乘以数量的绝对值补全金额；东方财富优先使用成交金额。不使用含手续费的发生金额代替成交金额。
  数据不足且无法推算托管金额时，相关收益、成本和托管净额显示为“—”，报告标记为不完整；缺失金额不能用占位单价零补成已知零金额，显式披露的成交金额零仍保留。逆回购价格为年化利率，不参与金额、单价、数量的乘除换算。
  东方财富同日、同证券、同数量的零金额撤指转出与指定入账逐条配对抵消；零数量零金额的指定交易及撤销指定不影响资产。
- 整份文件无有效托管转入转出业务时，概览隐藏托管项目，证券表隐藏托管净转入列；有转移但净额为零时仍保留。证券表中的手续费合计、各手续费分项和分红净额在所有明细均为零时隐藏；各表只在有备注内容时显示备注列。证券表后以弱化提示列出被隐藏的列及对应原因。
- 逆回购拆出净支出扣除明列费用得到本金，拆出费用即时扣减收益。
  拆出与购回按平台、证券代码及平台指定的逆回购编号配对：招商证券使用合同编号，东方财富使用流水号；东方财富的成交编号在拆出与购回中可能不同，仅用于交易身份及跨文件去重。同一编号的多笔拆出合并核算，部分购回按本金比例分摊拆出费用。双方均未披露编号时，仅允许本金及数量唯一匹配；缺失或歧义配对停止核算。
  购回按平台流水数量还原本金：招商上海 204 系列每单位 1,000 元，深圳 1318 系列每单位 100 元；东方财富每单位 100 元。
  购回净收款减本金为净利息；未到期本金并入剩余成本，未到期原始数量并入剩余数量。
  概览单列逆回购净收益与逆回购手续费，均已包含在对应合计中。逆回购手续费备注显示其占交易总额的千分比及占手续费的百分比。逆回购净收益备注的“年化收益率”已扣除手续费：已完成交易净收益合计 × 365 ÷ Σ（对应本金 × 计息天数），未到期费用不参与该收益率。计息天数由购回税费前利息 × 365 ÷（本金 × 成交价格 / 100）反推，仅接受分位舍入后唯一吻合的正整数；缺少有效报价或无法唯一确定天数时显示不可计算。
- 交收资金修正仅保留流水统计，不参与收益、净投入、持仓和费用核算，也不作为待确认业务；逆回购本金与收益以拆出和购回记录核算。
- 印花税、佣金、经手费、证管费、结算费、过户费和其他费用分别累计，
  与证券收益合并展示，按已实现净收益降序排列，无法确定收益的证券置后，末行显示合计。费用已经包含于净收付款，不再次扣减。
- 核算保留 Decimal 精度；展示金额逐证券四舍五入至分，再相加得到概览与合计，避免可见明细相加相差一分钱。零值不显示负号。数量合计仅为原始单位之和，不表示统一资产单位。
- 交易笔数为买入、卖出及逆回购拆出的流水记录数，不等同于委托单数。

不计算当前市值或总资产。完整账户收益需要完整交易流水及托管转入转出的成交金额。
无法解析的行或不足的持仓成本会停止报告，未知业务会列明并将报告标记为
不完整（退出码 1）；输入错误退出码 2。工具不会静默将未知业务认作银行转账。

## 双策略口径

两种策略由 Python 同时计算，页面统一切换所查看的情景，数量与收益不能相加：

- **A `retained_buy_pairing`（未完成买入保留策略）**：卖出匹配最高的严格可盈利买入价；买入匹配最低的严格可低价回补卖出价。已完成配对不被后续交易改写。亏损卖出不删除原买入期待，因此未完成买量可能大于实际持仓。已完成配对价差是策略归因，不等于券商或移动加权成本已实现盈亏。
- **B `current_position_lots`（当前持仓批次策略）**：每笔买入创建真实批次；卖出先消耗最高可盈利成本，再按最高成本消耗亏损或持平批次。非盈利卖出创建回补目标。后续低价买回可消耗目标，但买入总会创建新持仓；回补改善只说明，不重复计收益。当前批次均价与 `earnings` 移动加权成本分别展示。

参考期待线采用不含费用的成交价，严格要求卖价大于买价、回补价小于卖价；等价不算盈利。每笔线都有来源与起点，已完成线默认隐藏并在完成日期结束，部分完成保留数量变化记录。A/B 均用独立的买卖现金流加剩余持仓估值校验；费用、分红按原净现金流单独衔接一次。整轮现金流回本价只是另一参考项。

未来计划的候选卖价按账户与券商共享一个可卖上限，不将多条期待的上限相加。普通股票按 T+1 估算，并排除当日买入期待；这不是券商实时可用数量。场内基金的交收类别无法仅凭当前输入确定，可卖量显示未知。详情摘要展示流水持仓与账本持仓均价，不再单列“可卖估算 · T+1”。账本持仓均价为剩余移动加权成本除以持仓量，含原买入费用；它不随 A/B 策略切换而变化。策略未完成买入均价和当前批次均价仍各有其配对口径，不代替账本持仓均价。后端数量约束仍以查看当天为准：当天收盘后导入的数据会扣除当天买入量，次日通常恢复为流水持仓；这不是下一交易日的承诺可卖量。回补计划不代表资金充足或无限加仓。操作手数默认每手 100 股；特殊证券的最小委托量需用户另行确认。

费率默认值为买卖佣金各万 1、每边最低 5 元（买卖两侧可分别取消最低佣金）、卖出印花税万 5、双边过户费十万 1，并非对个人东方财富合同费率的承诺。基金等需按实际适用费率调整。后端按选定数量计算双边费用并求严格盈利的首个报价档位：普通股票 0.01 元、已支持场内基金 0.001 元。历史净现金流不因修改未来费率而改变。

未来计划表只列尚未完成且有计划数量的项目，按来源日期倒序排列。A 策略保留的买入参考数量可能超过实际持仓，卖出计划仍受真实持仓上限约束；零持仓不列出卖出计划，但保留图上的策略参考线，不改变历史配对。“已完成历史”仅控制图表历史线。费率和手数可通过滑块或数字输入修改，并在浏览器本地保存。

证券摘要中的持仓市值 = 最新价格 × 流水持仓量；持仓浮盈 = 持仓市值 − 账本剩余成本；浮盈率 = 持仓浮盈 ÷ 剩余成本 × 100%。成本未知、缺少最新价格时相应数值显示未知，剩余成本为零时不计算浮盈率。这些数值独立于 A/B 配对策略，不把已实现配对收益再次计入持仓浮盈。

总经济盈亏 = 交易净现金流 + 剩余持仓现价估值（包含费用、分红等账本调整）。零持仓时无需行情即可确定；有持仓而缺少现价时保持未知。其右下角差额 = 总经济盈亏 − 策略已实现价差，百分比 = 差额 ÷ 已实现价差绝对值；已实现价差为零时不显示百分比。这是两种核算口径的差异，不是账户投资收益率。

计划表的“当前可执行”使用现价和所设操作量，按双边费用后的首个盈利报价判断。卖出还共享同一账户、券商的 T+1 可卖上限；基金可卖量未知时不推定可以卖出。买回提示表示价位已达标，不核验账户可用资金。候选卖价的模拟数量单独展示，不与当前可执行数量混用；多条卖出参考是可选价位，计划数量不能直接相加。
